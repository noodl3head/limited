# Product Scope

## North Star

Reduce phone use for riders. The assistant should work as a spoken companion, not as another path back to the screen.

## Sarvam-Owned Lane

The strongest AI-owned use case is information flow:

- news briefs
- thoughts and questions
- Dhoni-first perspective
- short explanations
- ride-safe recommendations

The assistant should answer briefly, then go deeper only when asked.

## BluArmor / OS-Owned Lane

These are better owned by BluArmor or native phone integrations:

- answering and ending calls
- Bluetooth/media buttons
- volume control
- basic play/pause/next controls

## Handoff Lane

These can begin conversationally but should hand off when needed:

- Google/Apple navigation
- detailed route inspection
- WhatsApp or SMS actions
- long recommendation comparisons

If a task requires visual attention, the assistant should ask the rider to stop and check the phone.
